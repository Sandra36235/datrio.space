Antes de copiar una fórmula

Los ejemplos usan tablas ficticias como Ventas, Productos y Calendario. Se muestran argumentos separados por comas; tu configuración regional puede usar punto y coma.

Excel: DAX funciona en Power Pivot y el modelo de datos, no como fórmula normal de una celda. Algunas funciones recientes son exclusivas de Power BI o dependen de la versión.

Cuatro ideas que hacen funcionar DAX

Entendelas antes de memorizar funciones.

Medida

Se calcula al consultar el informe. Cambia con segmentadores, filas, columnas y filtros. Ejemplo: Ventas = SUM(Ventas[Importe]).

Columna calculada

Se evalúa fila por fila y se guarda en el modelo. Úsala si necesitas un atributo estable para segmentar o relacionar.

Contexto de filtro

Es el conjunto de filtros activo para un cálculo. CALCULATE puede modificarlo.

Contexto de fila

Es la fila que una expresión está recorriendo. Aparece en columnas calculadas y funciones iteradoras como SUMX.

Recetas para tus informes

Creá primero la medida Ventas = SUM(Ventas[Importe]). Después adaptá estas medidas a tu modelo. Para cálculos de tiempo, necesitás una tabla Calendario continua y relacionada con Ventas.

Participación de cada categoría

Compara la categoría visible con el total de categorías bajo los demás filtros del informe.

% categoría =
DIVIDE(
    [Ventas],
    CALCULATE([Ventas], REMOVEFILTERS(Productos[Categoría]))
)

Crecimiento frente al año anterior

Compara un período con el mismo período del año previo.

Crecimiento anual % =
VAR Anterior =
    CALCULATE([Ventas], SAMEPERIODLASTYEAR(Calendario[Fecha]))
RETURN
    DIVIDE([Ventas] - Anterior, Anterior)

Ventas de los últimos 12 meses

Calcula una ventana móvil hasta la fecha máxima del contexto.

Ventas 12 meses =
CALCULATE(
    [Ventas],
    DATESINPERIOD(Calendario[Fecha], MAX(Calendario[Fecha]), -12, MONTH)
)

Ranking visible de productos

Ordena los productos según ventas y conserva las selecciones externas del informe.

Ranking producto =
RANKX(
    ALLSELECTED(Productos[Nombre]),
    [Ventas],
    ,
    DESC
)

Power BI y Excel: dónde usar DAX

Power BI: creá medidas en el modelo para cálculos que respondan a los visuales. Las columnas calculadas sirven para atributos persistentes; Power Query suele ser mejor para limpieza de datos.

Excel: trabajá con DAX en Power Pivot o en el modelo de datos de una tabla dinámica. Las fórmulas de celdas comunes usan el lenguaje de Excel. La disponibilidad de funciones DAX puede variar según la versión.
